# Еженедельный отчёт по Метрике → Telegram (MDMprint)

Раз в неделю (понедельник утром) тянет из Яндекс.Метрики цифры за прошлую неделю,
сравнивает с позапрошлой, прогоняет через правила и присылает короткий отчёт с
рекомендациями в Telegram.

## Как работает

- `metrika-weekly.mjs` — весь скрипт (без внешних зависимостей, только Node 20+).
- `.github/workflows/weekly.yml` — расписание (GitHub Actions) + кнопка ручного запуска.

## Секреты (Settings → Secrets and variables → Actions)

| Имя | Значение |
|---|---|
| `METRIKA_TOKEN` | OAuth-токен Яндекс.Метрики (права: чтение статистики) |
| `COUNTER_ID` | `91973` |
| `TG_BOT_TOKEN` | токен Telegram-бота (@BotFather) |
| `TG_CHAT_ID` | id получателя |

## Проверить вручную

Actions → «Еженедельный отчёт…» → **Run workflow**. Отчёт придёт в Telegram сразу.

## Локально

```
METRIKA_TOKEN=… TG_BOT_TOKEN=… TG_CHAT_ID=… node metrika-weekly.mjs
# или без отправки, просто печать:
DRY=1 METRIKA_TOKEN=… node metrika-weekly.mjs
```

## Правила-рекомендации

Заложены пороги (растёт/падает на N пунктов) для: отказов на мобильных, общих отказов,
конверсий (заявка / мессенджер / телефон), трафика. Правки — в функции `rules()`.
